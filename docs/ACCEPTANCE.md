# Career Based Advising — public acceptance criteria

Derived from elicitable stakeholder needs (Phase 1). Instructor private defects are **not** listed here.

## Scope

1. Graded users are **enrolled university** students (programme + courses). High-school pathways are out of scope.
2. Passwords hashed; login never returns password material.

## Exploration

3. Support **both** modes: career→courses and courses→careers.
4. Recommendations are ranked **suited options** with non-absolute wording — never a single forced career.
5. Students can edit programme/courses/interests and re-run exploration after changing goals.
6. Career info includes realistic entry-level notes plus salary/progression-style context.

## Gaps

7. System can identify missing required courses for a target path.
8. After identification, there is **no** enrolment, provider, or booking workflow.
